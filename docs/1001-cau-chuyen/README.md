# 1001 Câu chuyện cùng Guitar — Tài liệu dự án

> Trang con `/story` của class.vananhaudio.com. Mã nguồn: `src/story/`,
> `supabase/functions/story-ai/`, `db/story_setup.sql`.

**AI/dev tham gia code: đọc theo thứ tự này trước khi viết dòng nào:**

1. `PROJECT_CONTEXT.md` — Single Source of Truth (mọi quyết định đã chốt)
2. `MIRA_CONSTITUTION.md` — Hiến pháp Mira, **đứng trên mọi tài liệu khác về Mira**
3. `10_Growth_Loop_va_Cuon_sach_song.md` — Cuốn sách sống + Growth Loop
4. `UX-FLOW-KE-CHUYEN.md` — trải nghiệm từng bước (B0–B8)
5. `database.md` + `api.md` — dữ liệu & API

Quy tắc: nếu code mâu thuẫn tài liệu — **tài liệu luôn đúng**. Xong mỗi
hạng mục phải cập nhật `PROJECT_CONTEXT.md` + `CHANGELOG.md`.

Bản gốc tài liệu do thầy Văn Anh giữ tại `~/App/1001 câu chuyện/` (máy
thầy); bản trong repo này là bản đồng bộ để cộng tác — ai sửa tài liệu
thì sửa CẢ HAI nơi hoặc báo thầy.
